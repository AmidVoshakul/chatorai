# Централизованная система проверки интернет-соединения

## Обзор

Реализована единая централизованная логика проверки наличия интернет-соединения для всего приложения ChatORAI.

## Архитектура

### 1. NetworkService (Singleton)
- **Файл**: `lib/services/network_service.dart`
- **Назначение**: Централизованная проверка состояния сети
- **Функциональность**:
  - Автоматическая проверка при старте приложения
  - Мониторинг изменений состояния подключения
  - Периодическая проверка каждые 30 секунд
  - Проверка реального доступа к интернету (ping нескольких хостов)
  - Управление состоянием SnackBar

### 2. NetworkAwareWidget
- **Файл**: `lib/widgets/network_aware_widget.dart`
- **Назначение**: UI-обертка для управления SnackBar
- **Функциональность**:
  - Автоматическое отображение/скрытие SnackBar
  - Локализованные сообщения
  - Возможность скрытия пользователем
  - Красивый дизайн с анимацией

### 3. Интеграция с OpenRouter Service
- **Файл**: `lib/services/openrouter_service.dart`
- **Изменения**: Добавлена проверка сети перед всеми сетевыми запросами
- **Методы с проверкой**:
  - `streamChatCompletion()`
  - `getAvailableModels()`
  - `uploadFile()`
  - `isHealthy()`
  - `testProviderStructure()`

## Поведение системы

### При запуске приложения
1. Автоматическая проверка наличия интернета
2. Если интернет отсутствует → показывается SnackBar
3. Если интернет есть → ничего не отображается

### При потере соединения
1. Автоматическое отображение SnackBar
2. Предотвращение множественных уведомлений
3. Уважение выбора пользователя (если скрыл → не показывать)

### При восстановлении соединения
1. Автоматическое скрытие SnackBar
2. Сброс флага отклонения пользователем
3. Никаких дополнительных уведомлений

## Возможности пользователя

- **Чтение чатов без интернета**: Чаты доступны для чтения офлайн
- **Скрытие SnackBar**: Пользователь может закрыть уведомление
- **Автоматическое восстановление**: При возврате сети SnackBar скроется

## Установка и использование

### 1. Сервис автоматически инициализируется в main.dart:
```dart
ChangeNotifierProvider(create: (_) => NetworkService())
```

### 2. Оборачивание UI в NetworkAwareWidget:
```dart
NetworkAwareWidget(
  child: YourWidget(),
)
```

### 3. Проверка состояния сети в коде:
```dart
final networkService = Provider.of<NetworkService>(context);
if (networkService.isConnected) {
  // Выполняем сетевые запросы
}
```

## Технические детали

### Проверка подключения
- Используется `connectivity_plus` для определения состояния
- Дополнительная проверка через `InternetAddress.lookup()`
- Проверка нескольких хостов для надежности:
  - google.com
  - cloudflare.com
  - openrouter.ai

### Управление состоянием
- `NetworkStatus.connected` - есть подключение
- `NetworkStatus.disconnected` - нет подключения
- `NetworkStatus.checking` - проверка в процессе

### Безопасность
- Запросы не выполняются при отсутствии сети
- Предотвращение утечек ресурсов
- Правильная очистка listeners

# Реализация голосового ввода в ChatInput

## Обзор

Реализована функция голосового ввода сообщений через микрофон. Кнопка микрофона отображается когда поле ввода пустое и нет прикрепленных файлов.

## Структура файлов

### 1. `lib/services/speech_to_text_service.dart`
Сервис для работы с распознаванием речи.

**Основные методы:**
- `checkAvailability()` - проверяет доступность микрофона
- `startListening()` - начинает прослушивание
- `stopListening()` - останавливает прослушивание
- `cancelListening()` - отменяет прослушивание
- `dispose()` - очищает ресурсы

**Обработчики:**
- `onResult` - вызывается при получении текста
- `onError` - вызывается при ошибках
- `onListeningChanged` - вызывается при изменении состояния

### 2. `lib/utils/speech_utils.dart`
Утилиты для работы с голосовым вводом.

**Функции:**
- `getIcon()` - возвращает иконку в зависимости от состояния
- `getColor()` - возвращает цвет в зависимости от состояния
- `getTooltip()` - возвращает подсказку для кнопки
- `getStatusText()` - возвращает текст статуса
- `canShowMicrophone()` - проверяет, можно ли показать микрофон
- `formatListeningTime()` - форматирует время прослушивания

### 3. `lib/widgets/chat/chat_input.dart`
Обновленный виджет ввода сообщений.

**Изменения:**
- Добавлен `SpeechToTextService` для работы с микрофоном
- Добавлены состояния `_isListening` и `_speechError`
- Обновлен метод `_startSpeechToText()` для использования сервиса
- Добавлен метод `_buildSpeechStatus()` для отображения статуса
- Обновлена логика отображения иконки кнопки

### 4. Локализация
Добавлены новые строки в файлы локализации:
- `startListening` - "Начать голосовой ввод" / "Start voice input"
- `stopListening` - "Остановить голосовой ввод" / "Stop voice input"
- `listening` - "Говорите..." / "Listening..."
- `micUnavailable` - "Микрофон недоступен" / "Microphone unavailable"
- `sendMessage` - "Отправить сообщение" / "Send message"

## Логика работы

### Отображение кнопки
Кнопка микрофона показывается когда:
1. Не идет стриминг ответа (`!isStreaming`)
2. Поле ввода пустое (`text.isEmpty`)
3. Нет прикрепленных файлов (`!hasAttachment`)

### Поведение кнопки
- **Пустое поле + нет файлов**: Показывает микрофон 🎤
- **При нажатии**: Запускает распознавание речи
- **Во время распознавания**: Показывает стоп ⏹️ и индикатор
- **При ошибке**: Показывает ошибку в SnackBar

### Статус под полем ввода
Отображается когда:
- Пустое поле и нет файлов
- Показывает текущее состояние:
  - 🎤 "Говорите..." - микрофон активен
  - ⚠️ "Ошибка..." - произошла ошибка
  - 🎤 "Микрофон недоступен" - нет доступа

### Обработка ошибок
Сервис обрабатывает следующие ошибки:
- `error_no_match` - не удалось распознать
- `error_speech_timeout` - таймаут ожидания
- `error_network` - проблемы с сетью
- `error_not_authorized` - нет разрешения
- `error_server` - ошибка сервера
- `error_too_many_requests` - слишком много запросов

## Поддерживаемые платформы

- **Android**: Требует разрешение `RECORD_AUDIO`
- **iOS**: Требует разрешение `NSMicrophoneUsageDescription`
- **Desktop**: Может не поддерживаться в зависимости от ОС

## Примечания

1. На десктопе может потребоваться дополнительная настройка микрофона
2. Для iOS нужно добавить в Info.plist:
   ```xml
   <key>NSMicrophoneUsageDescription</key>
   <string>Для голосового ввода сообщений</string>
   ```
3. Для Android нужно добавить в AndroidManifest.xml:
   ```xml
   <uses-permission android:name="android.permission.RECORD_AUDIO" />
   ```

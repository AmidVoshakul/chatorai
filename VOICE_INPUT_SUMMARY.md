### Сценарии использования:
1. **Пустое поле** → Показать микрофон 🎤
2. **Нажатие на микрофон** → Начать слушать
3. **Говорите** → Текст появляется в поле
4. **Остановка** → Текст готов к отправке
5. **Ошибка** → Показать сообщение

## 🔒 Безопасность и разрешения

### Требуемые разрешения
**Android** (`AndroidManifest.xml`):
```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

**iOS** (`Info.plist`):
```xml
<key>NSMicrophoneUsageDescription</key>
<string>Для голосового ввода сообщений</string>
```

### Приватность
- ❌ Данные не отправляются на сторонние серверы
- ✅ Локальная обработка через speech_to_text
- ✅ Пользовательский контроль разрешений
